# Outputs

Ce répertoire contient les fichiers générés par Ollama.

Les résultats des différentes exécutions et expérimentations sont stockés ici pour référence et analyse ultérieure.

| Emplacement | Contenu |
|---|---|
| `outputs/` | Fichiers de code générés, images générées (`img_*.png`) |
| `outputs/documents/` | Documents générés (docx, pdf, pptx, xlsx…) et copies modifiées des pièces jointes (`<nom>_modifie.<ext>`) |
| `outputs/artifacts/` | Pages HTML temporaires du volet d'aperçu |
| `outputs/exports/` | Conversations exportées (Markdown, HTML, PDF) |
| `outputs/scheduled/` | Rapports des tâches planifiées |
